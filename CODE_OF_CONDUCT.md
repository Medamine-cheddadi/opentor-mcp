# Code of Conduct

## Our standard

We want OpenTor MCP to be a welcoming, practical project. Be respectful, assume good intent, give
actionable feedback, and keep technical disagreement focused on the work.

Unacceptable behavior includes harassment, discrimination, threats, doxxing, sexualized conduct,
deliberate disruption, sharing another person's private information, or using project spaces to
coordinate harmful or unauthorized activity.

## Scope

This code applies to issues, pull requests, discussions, reviews, and other spaces managed by the
project. Maintainers may remove content or restrict participation when behavior puts contributors,
users, or the project at risk.

## Reporting

For a conduct concern, open an issue titled `[Conduct] Request private contact` without including
sensitive details; the maintainer will arrange a private channel. Security vulnerabilities must
follow [SECURITY.md](SECURITY.md). Reports will be reviewed fairly and with respect for the privacy
of everyone involved.
